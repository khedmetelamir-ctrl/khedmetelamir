# خدمة الأمير

نسخة PWA عربية RTL لإدارة خدمة مدارس الأحد/الخدمة، تعمل من المتصفح ويمكن تثبيتها على الهاتف بدون متجر.

## أهم الوظائف
- تسجيل دخول وحساب جديد + تذكر الدخول + استعادة كلمة المرور.
- مدير خدمة وخدام، مع إسناد الخدام للفصول.
- الخادم يرى الفصول والمخدومين المسندين إليه فقط.
- مشاركة بيانات الفصل بين الخدام المعيّنين له عبر Supabase Realtime.
- إضافة وتعديل وحذف المخدومين (التعديل والحذف للمدير).
- إنشاء/تعديل/حذف الفصول (للمدير).
- الحضور: الفصل فقط، وتاريخ الاجتماع يُسجل تلقائيًا؛ الحالة الافتراضية للمخدوم حاضر ويمكن تغيير الغائب/المعتذر فقط.
- النقاط مع حد أدنى -10.
- أعياد الميلاد مرتبة حسب أقرب موعد مع حساب السن تلقائيًا.
- الزيارات/الافتقاد.
- التنبيهات.
- الإحصائيات والتقارير.
- صفحة «الملاحظات»: كل مستخدم نشط يستطيع كتابة وحفظ ملاحظة للمخدومين الذين يستطيع الوصول إليهم.
- PWA بأيقونة 192 و512.
- تصدير نسخة احتياطية واسترجاعها.

## التشغيل محليًا
لا تفتح `index.html` مباشرة بـ `file://` إذا كنت تريد تسجيل الدخول/استعادة كلمة المرور وPWA.

شغّل خادمًا محليًا مثل:

```bash
python -m http.server 3000
```

ثم افتح:

`http://localhost:3000`

## Supabase
الواجهة تستخدم Project URL وPublishable Key فقط، ولا تحتوي Service Role Key.

قاعدة البيانات الأساسية يجب أن تكون موجودة بالفعل. بعد ذلك شغّل:

`FINAL_SUPABASE_PATCH.sql`

مرة واحدة في Supabase SQL Editor.

هذا الملف يجمع إصلاحات:
- النقاط + حد -10.
- صلاحيات تعديل/حذف الفصول والمخدومين.
- الملاحظات المنفصلة.
- صلاحيات الملاحظات حسب صلاحية الوصول للفصل.
- Realtime للملاحظات.

## GitHub Pages
ارفع محتويات هذا المجلد إلى المستودع، ثم فعّل GitHub Pages من Settings → Pages → Deploy from branch.

> ملاحظة: GitHub Pages يحتاج HTTPS، وهو مناسب لتثبيت PWA. عدّل `start_url` و`scope` في `manifest.webmanifest` إذا وضعت التطبيق داخل مجلد فرعي بدل جذر الموقع.

## مهم
هذه النسخة تم فحص JavaScript فيها باستخدام `node --check` بعد التعديلات، وتم تنظيف النسخ البرمجية غير المستخدمة من الحزمة. لا يمكن من داخل ملف GitHub التحقق من حالة مشروع Supabase الفعلية؛ لذلك يجب تشغيل `FINAL_SUPABASE_PATCH.sql` على قاعدة المشروع نفسها.
